# Break-Glass Access

Break glass is an emergency access path for life, physical safety or comparable urgency when normal verification delay is unsafe. It is not a verification level or convenience bypass.

Required: active Case, precise field/purpose, structured reason and detail, dedicated permission, shortest practical expiry, manager pre-approval or narrowly defined highest-severity post-review, immediate security notification and automatic Privacy review queue. Raw access still requires pre-reveal Audit and object-level authorization. Repeated/out-of-hours use triggers anomaly review.
