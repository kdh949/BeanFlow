# Interaction and selection states

모든 canonical control은 색만으로 상태를 전달하지 않습니다. focus는 ring, invalid는 안전한 문구와
`aria-invalid`, disabled는 native disabled semantics, selected는 native checked/selected state를 함께 씁니다.

## Keyboard contract

- checkbox와 switch: `Space`
- radio: `ArrowLeft/Right/Up/Down`
- tabs: 방향키와 `Home/End`; 기본 manual activation은 `Enter/Space`로 확정
- icon action과 chip: native button activation
- 모든 interactive box: computed width와 height가 44px 이상

Remote view를 바꾸는 tabs는 기본 `manual` activation으로 방향키 탐색이 곧바로 API 요청을 만들지 않게
합니다. 즉시 local panel만 바꾸는 경우에만 `automatic`을 명시합니다.
