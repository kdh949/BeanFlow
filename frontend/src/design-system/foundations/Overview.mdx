# BeanFlow foundations

신규 고객·점주 화면에서 검증한 cool white, navy, coral 시각 언어가 전체 제품의 유일한 기준입니다.
`tokens/*.css`가 색, 글꼴, 여백, radius, elevation, motion의 canonical source이고 제품과 Storybook은
semantic token 또는 명시된 palette token만 소비합니다. 이전 espresso, caramel, crema token과 생성
snapshot은 제거됐습니다.

## Component catalog

이 Overview는 foundation token을 실제로 소비하는 canonical component의 대표 상태를 함께 보여줍니다.
상세 API와 disabled, invalid, loading 같은 추가 상태는 왼쪽 Components 문서에서 확인합니다.

- Korean UI: `--font-sans`
- identifiers and pickup numbers: `--font-mono`
- headings: tight `--ls-title` with one `h1` per page
- helper text: body hierarchy 안에서 필요한 경우에만 사용

`WorkspaceFrame`은 sidebar, topbar와 content slot의 geometry만 소유합니다. Store, Support, Operations는 서로의
sidebar/topbar를 재사용하지 않으며 각 surface의 canonical shell이 menu, route, actor와 failure 상태를
presentation-safe props로 연결합니다.

### Dense support workspace

<Story of={DenseWorkspaceStories.Catalog} />

고객지원의 밀도 높은 화면은 새 shell을 만들지 않고 `SupportWorkspaceShell` 안에서 아래 네 경계를 지킵니다.

- **REUSE**: foundation token, field, button, feedback, status, `WorkspaceFrame`
- **COMPOSE**: 화면별 카드, master/detail, 검색 결과와 transaction action 영역
- **EXTEND**: 고객지원 sidebar route와 이 Overview의 workspace 사용 규칙
- **NEW**: 도메인과 API를 소유하지 않는 `WorkspaceDataTable`, `FilterToolbar`, `MetricStrip`, `EventTimeline`, `WorkflowStepper`

표와 timeline은 긴 한국어 문구가 있어도 가로 scroll과 명시적 caption을 유지합니다. 필터와 action은 keyboard
순서대로 접근할 수 있어야 하며 loading, empty, dependency error, permission 상태를 같은 영역에서 구분합니다.

공용 `.surface-card`, `.context-label`, `.customer-page`, `.console-page`, `.panel-heading`, `.back-link`,
`.bf-icon-action`, `.bf-chip-action`, `.inline-note`, `.form-error`, `.form-footnote`는 design-system 소유 pattern CSS입니다.
`src/styles.css`에는 route/feature-specific layout만 둡니다.

## Elevation and motion

- default surfaces: border first, `--sh-0` or `--sh-1`
- floating search and decision surfaces: `--sh-2`
- focus: `--ring-focus`; destructive focus: `--ring-danger`
- reduced motion sets duration tokens to `0ms`

## New token checklist

새 token은 semantic name, owner layer, affected surface, usage와 consumer story를 기록합니다. 화면 하나의
literal을 숨기기 위한 token이나 두 번째 palette scale은 추가하지 않습니다.
