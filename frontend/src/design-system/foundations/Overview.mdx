# BeanFlow foundations

`tokens/*.css`가 색, 글꼴, 여백, radius, elevation, motion의 canonical source입니다. 제품과
Storybook은 palette 값이 아니라 semantic token을 소비합니다. 현재 token 정의는 201개이며,
`_ds_manifest.json`의 187개 snapshot과 type 분류는 migration 참고값일 뿐입니다.

Text roles are `--text-strong`, `--text-body`, `--text-muted`, `--text-faint`, and
`--text-accent`. On a sunken `--crema-200` surface, use `--text-body`; muted text does not
meet AA on that background. The approved softer borders are `--border-info-soft`,
`--border-success-soft`, `--border-warning-soft`, and `--border-danger-soft`.

- UI and Korean body: `--font-sans`
- identifiers and pickup numbers: `--font-mono`
- currency and quantities: tabular numerals through `.bf-num`
- headings: `--fs-title-*` with `--ls-title`
- body: `--fs-body*` with `--lh-body`

## Spacing and geometry

<div className="foundation-space-row" aria-label="spacing token scale example"><span /><span /><span /><span /><span /></div>

Use `--sp-2`, `--sp-4`, `--sp-6`, `--sp-8`, and `--sp-10` for the example above. Controls
use `--r-control`; cards use `--r-card`; pill badges use `--r-pill`. Literal dimensions are
reserved for intrinsic icons, media, minimum hit targets, charts, and breakpoints.

## Elevation and motion

- cards: `--sh-1`; hover: `--sh-2` or `--sh-3`; dialogs: `--sh-4`
- customer device frame: `--sh-customer-frame`
- focus: `--ring-focus`; destructive focus: `--ring-danger`
- micro interaction: `--dur-fast`; normal transition: `--dur-base`; sheet: `--dur-sheet`
- reduced motion changes all duration tokens to `0ms`

## New token checklist

A new token must record its semantic name, owner layer, affected surfaces, usage here, and a
story that renders it. Do not add a token solely to disguise a one-off value.
