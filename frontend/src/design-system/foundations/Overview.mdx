# BeanFlow foundations

신규 고객·점주 화면에서 검증한 cool white, navy, coral 시각 언어가 전체 제품의 유일한 기준입니다.
`tokens/*.css`가 색, 글꼴, 여백, radius, elevation, motion의 canonical source이고 제품과 Storybook은
semantic token 또는 명시된 palette token만 소비합니다. 이전 espresso, caramel, crema token과 생성
snapshot은 제거됐습니다.

Status는 채워진 초록 배지로 성공을 장식하지 않습니다. 디자인 시스템 `StatusText`는 전달받은 문구와
tone만 렌더링합니다. 서버 상태의 문구와 tone 해석, 알 수 없는 code 보존은 application presentation
pattern인 `DomainStatusText`가 담당합니다.

강조 위계는 `strong > body > muted > faint` 순서입니다. 각 semantic 이름은 실제 대비 농도와 같은
방향을 유지해야 합니다.

- Korean UI: `--font-sans`
- identifiers and pickup numbers: `--font-mono`
- headings: tight `--ls-title` with one `h1` per page
- helper text: body hierarchy 안에서 필요한 경우에만 사용

## Spacing and geometry

<div className="foundation-space-row" aria-label="spacing token scale example"><span /><span /><span /><span /><span /></div>

모바일 gutter는 `--gutter-mobile`, workspace gutter는 `--gutter-desktop`을 사용합니다. Controls use
`--r-control`; cards use `--r-card`. 큰 둥근 카드와 장식 shadow를 반복하지 않습니다.

공용 `.surface-card`, `.context-label`, `.customer-page`, `.console-page`, `.panel-heading`, `.back-link`,
`.icon-action`, `.inline-note`, `.form-error`, `.form-footnote`는 design-system 소유 pattern CSS입니다.
`src/styles.css`에는 route/feature-specific layout만 둡니다.

## Elevation and motion

- default surfaces: border first, `--sh-0` or `--sh-1`
- floating search and decision surfaces: `--sh-2`
- focus: `--ring-focus`; destructive focus: `--ring-danger`
- reduced motion sets duration tokens to `0ms`

## New token checklist

새 token은 semantic name, owner layer, affected surface, usage와 consumer story를 기록합니다. 화면 하나의
literal을 숨기기 위한 token이나 두 번째 palette scale은 추가하지 않습니다.
