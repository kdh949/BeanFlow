## 제공 범위

- 연결 완료: 기존 Support Case·timeline 조회와 페이지네이션, 주문 보드 상세의 제조 품목·옵션, 매장 메뉴·가격·수동 판매 상태와 주문 접수 정책 관리.
- 준비 중 유지: 매장 영업시간 관리, 운영 요약/복구 목록/운영 업무, 이의제기 상세·재심,
  상담 후속의 별도 승인·해결·정보 변경·긴급 열람 목록 화면. Runtime 목록/조회 또는 화면 연결이 없는 기능이다.
- 매장 지역은 검색·지정과 저장 응답만 제공한다. 현재 저장된 지역의 별도 GET은 제공되지 않으며 검색 결과를 현재 설정으로 표시하지 않는다.
- 후속 업무의 디자인 fixture를 실제 데이터가 연결된 화면으로 사용하지 않는다. 제품은 별도의 Follow-up route로 Case와 timeline만 읽는다.
